# 量潮客户支持

你提的问题会被认真答；答完给你一份工作日志，你确认了，这一单才算办完。

## 客户视角的三步

1. **提问**：各个渠道都收；
2. **收到回答**：外加一份写清楚「问了什么、答了什么、依据什么」的工作日志；
3. **你确认**：或不确认也行——不确认的问题按超时关掉，记录还在，下次回来不用重讲背景。

## 你能期待的两件事

- 同类问题第二次来，不用重新解释你的环境；
- 答案会沉淀成解决方案，下次可能直接给你；给之前会先确认你的环境。

## 我们答得出来的问题

- 制度怎么解读；
- 操作怎么做；
- 事情找谁、去哪办；
- 业务为什么变成这样。

## 保密边界

你的问题与工作日志只在量潮内部使用，不进任何对外案例，除非另行获得授权。
